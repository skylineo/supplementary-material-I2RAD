# Anonymous GitHub Pages deployment

1. Create a fresh GitHub account with no personal name, avatar, email, organization,
   or link. Use an email address created only for double-blind review.
2. Create a public repository with a neutral name, for example
   `i2r-ad-supplementary`.
3. Upload the repository-root files together with the `videos/` directory.
4. In **Settings → Pages**, select **Deploy from a branch**, choose the default
   branch and the repository root, then save.
5. Use the resulting `https://<anonymous-account>.github.io/<repository>/` URL.

Before sharing the link, inspect the public account page, repository history,
video metadata, filenames, overlays, and page source from a private browser window.

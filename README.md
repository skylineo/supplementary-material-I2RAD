# I2R-AD Supplementary Material

Anonymous supplementary website for double-blind review.

## Update content

1. Place `success-01.mp4` through `success-06.mp4` and `failure-01.mp4`
   through `failure-03.mp4` in `videos/`.
2. Edit `site-data.js` to update scene names, titles, observations, and paths.
3. Keep the repository account, profile, commit identity, filenames, video
   overlays, audio, and metadata anonymous.

See `GITHUB-PAGES.md` for publishing instructions.
